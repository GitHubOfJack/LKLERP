## Why

一家约50人的小公司目前缺乏统一的HR管理系统，出勤数据散落在钉钉、绩效评分依赖纸质表格或Excel、工资计算靠人工手动操作，效率低且易出错。需要一套低维护成本的自建ERP系统，将出勤、绩效、工资三个核心模块数字化、自动化，减少人工操作和出错概率。

## What Changes

- 新增钉钉考勤数据导入功能，支持 Excel/CSV 格式，将钉钉打卡数据统一纳入系统管理
- 新增排班管理，支持班次定义、默认班次和少数倒班员工的周期排班
- 新增考勤审批流程，包括请假、加班、补卡、换班等单级审批
- 新增外出/出差登记与跟踪
- 新增月度考勤汇总，自动统计出勤天数、迟到早退、加班时数（区分平时/周末/节假日）
- 新增绩效评分管理，支持可配置的评分维度和权重，上级打分，评分结果转化为绩效系数
- 新增工资核算模块，包含基本工资+岗位工资+绩效工资+各类补贴的工资结构
- 新增社保公积金自动计算，支持按城市配置缴费比例和基数
- 新增个人所得税累计预扣法计算，支持专项附加扣除
- 新增工资条在线查看（PC端），工资发放后员工可自助查看明细
- 新增中国法定节假日日历管理，支持每年更新和调休工作日标记
- 新增站内消息通知，替代外部通知渠道
- 新增基于角色的权限控制（超级管理员/HR/部门主管/普通员工）

## Capabilities

### New Capabilities

- `attendance`: 出勤管理——钉钉数据导入、排班管理、审批流程（请假/加班/补卡/换班）、外出出差跟踪、月度考勤汇总
- `performance`: 绩效管理——评分周期配置、维度评分模板、上级打分流程、绩效等级与系数映射
- `payroll`: 工资管理——工资结构与项目配置、社保公积金方案、个税累计预扣计算、月度工资核算与发放、工资条查看
- `org-structure`: 组织架构——部门管理、岗位管理、员工档案、审批链（上级关系）、工资档案
- `notification`: 站内通知——消息中心、审批提醒、评分提醒、工资条通知
- `holiday-calendar`: 节假日日历——中国法定节假日、调休工作日、年度日历管理

## Impact

- **技术栈**：Python + Django + DRF（后端），Vue3 + Ant Design Vue + Vite（前端），SQLite/PostgreSQL（数据库），Redis + Celery（定时任务），Docker Compose（部署）
- **外部依赖**：钉钉考勤导出数据（Excel/CSV 格式），未来可扩展钉钉开放平台API
- **关键库**：openpyxl（Excel 读取）、python-docx / ReportLab（文档/PDF 导出）
- **部署环境**：自建Linux服务器，单机 Docker Compose 部署
- **数据安全**：工资等敏感数据需要权限隔离，员工仅可查看自己的数据
